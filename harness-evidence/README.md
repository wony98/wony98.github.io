# AI 에이전트 협업 하네스: 코드와 검증 근거

Claude·Codex의 요청과 회신을 Markdown 파일에 남기는 협업 도구입니다. 새 회신이 들어온 뒤 이전 상태로 답장을 추가하는 일을 막고, 회신이 필요한 요청을 조회합니다. 포트폴리오에 적은 검사 구조를 코드와 실행 기록으로 확인할 수 있도록 버전 0.7.0을 고정했습니다.

## 담당 범위

저는 프로젝트에서 반복된 협업 문제를 다른 작업에서도 해결할 수 있도록 스킬 확장을 요청했습니다. 적용 범위와 승인 기준을 정하고 구현·검토 결과를 확인했습니다. Python 도구의 구현에는 Codex를 활용했고 Claude가 교차검토했습니다. 이후 개선을 포함한 현재 코드이며, 전체 코드를 혼자 직접 작성했다는 의미는 아닙니다.

## 검증 기록

- [2026.10.23 기존 실행 요약](verification-20261023.json): 설치 환경에서 기존 회귀 테스트 36개 통과와 별도 실패 조건 4건을 기록한 원본 요약입니다. 전체 터미널 로그가 아닌 당시 결과 요약입니다.
- [회귀 테스트 원문](skill/scripts/test_thread_mailbox.py): 변경하지 않은 기존 테스트 코드입니다. 개인 환경의 Claude 연결 문서가 없으면 그 문서의 버전을 확인하는 1건은 원래 코드대로 건너뜁니다.
- [실패 조건 재현 코드](check_guards.py): 오래된 마지막 번호, 잘못된 작업 모드, 오래된 고정 내용 해시, 혼합 줄바꿈을 임시 기록에 입력합니다. 거부 종료코드와 변경 전후 SHA-256이 같은지 검사합니다.
- [공유용 사본 재실행 기록](verification-20261024.json): 기존 36개 전체 통과 주장과 구분해 실제 통과·건너뜀·실패 수를 기록합니다.
- [파일별 원본 해시](source-manifest.json): 설치본에서 복사한 파일과 10월 23일 요약 기록의 SHA-256입니다. 내부 대화와 개인 연결 문서는 포함하지 않았습니다.

## 재실행

Python 표준 라이브러리만 사용합니다. 이 폴더 전체를 받은 뒤 실행합니다. 스킬 설치나 실제 운영 스레드는 필요하지 않습니다.

```sh
python -B skill/scripts/test_thread_mailbox.py -v
python -B check_guards.py
```

테스트는 임시 디렉터리의 합성 기록을 사용합니다. 위 명령은 새 결과를 터미널에 출력하며 제공된 기존 검증 기록을 덮어쓰지 않습니다. 개인 Claude 연결 문서는 포함하지 않았으므로 공유용 사본에서는 관련 1건이 건너뛰어집니다. 설치 스킬의 표준 메시지 형식과 다른 기존 기록에는 별도 호환 처리가 필요합니다.
